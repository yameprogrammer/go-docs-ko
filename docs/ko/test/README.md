`test` 디렉토리는 Go 툴체인과 런타임의 테스트들을 포함하고 있습니다.
여기에는 black box 테스트, 회귀(regression) 테스트, 그리고 에러 출력 테스트가 포함됩니다.
이 테스트들은 `all.bash`의 일부로 실행됩니다.

이 테스트들만 실행하려면 다음을 실행하세요:

../bin/go test cmd/internal/testdir

이 디렉토리의 특정 파일에 있는 테스트만 실행하려면 다음을 실행하세요:

../bin/go test cmd/internal/testdir -run='Test/(file1.go|file2.go|...)'

표준 라이브러리 테스트는 적절한 패키지 내에 일반적인 Go 테스트로 작성해야 합니다.

툴체인과 런타임의 패키지들에도 일반적인 Go 테스트가 포함되어 있습니다.
이 디렉토리에 새로운 테스트를 추가하는 주요 이유는 다음과 같습니다:

* 테스트 러너(test runner)를 사용하는 것이 가장 자연스럽게 표현됩니다. 또는
* `gccgo` 및 기타 Go 툴체인에도 적용 가능합니다.
