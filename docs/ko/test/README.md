`test` 디렉토리는 Go 툴체인과 런타임의 테스트를 포함하고 있습니다.
여기에는 블랙박스 테스트, 회귀 테스트 및 에러 출력 테스트가 포함됩니다.
이 테스트들은 `all.bash`의 일부로 실행됩니다.

이 테스트들만 실행하려면 다음을 수행하십시오:

../bin/go test cmd/internal/testdir

이 디렉토리 내의 지정된 파일에서만 테스트를 실행하려면 다음을 수행하십시오:

../bin/go test cmd/internal/testdir -run='Test/(file1.go|file2.go|...)'

표준 라이브러리 테스트는 해당 패키지 내에 일반적인 Go 테스트 형식으로 작성되어야 합니다.

툴체인과 런타임의 패키지들에도 일반적인 Go 테스트가 포함되어 있습니다.
이 디렉토리에 새로운 테스트를 추가하는 주요 이유는 다음과 같습니다.

* 테스트 러너(test runner)를 사용하여 표현하는 것이 가장 자연스럽습니다. 또는
* `gccgo` 및 기타 Go 툴체인에도 적용 가능합니다.
