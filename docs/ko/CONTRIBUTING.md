# Go에 기여하기

Go 프로젝트에 기여해주셔서 감사합니다! 이 가이드는 Go 소스 코드에 변경 사항을 제출하는 방법을 안내합니다.

## 변경 사항 제출 프로세스

Go의 메인 저장소는 직접적인 쓰기 권한이 제한되어 있습니다. 변경 사항을 제출하려면 다음 단계를 따르세요.

### 1. 이슈 생성 및 논의

코드 변경 사항을 제출하기 전에 [GitHub Issues](https://github.com/golang/go/issues)에서 이슈를 생성하여 제안 내용을 논의하는 것이 좋습니다. 특히 다음과 같은 경우에 권장됩니다.

- 새로운 기능을 추가하려는 경우
- 기존 동작을 변경하려는 경우
- 대규모 리팩토링을 계획하는 경우

### 2. 변경 사항 구현

코드를 작성할 때는 다음 원칙을 준수하십시오.

- **테스트**: 모든 변경 사항에는 적절한 테스트가 포함되어야 합니다. `go test`를 사용하여 모든 테스트가 통과하는지 확인하세요.
- **포맷팅**: 코드는 `gofmt`를 사용하여 포맷팅되어야 합니다.
- **문서화**: 공개 API의 변경 사항은 관련 문서에 반영되어야 합니다.

### 3. 변경 사항 제출 (Proposal/Review)

Go는 코드 리뷰 프로세스를 위해 특수한 워크플로우를 사용합니다.

1. **Fork 및 Push**: 저장소를 fork하고 변경 사항을 자신의 브랜치에 push합니다.
2. **Issue 업데이트**: 관련 이슈에 변경 사항이 포함된 커밋 링크를 게시합니다.
3. **리뷰 요청**: 리뷰어가 코드를 검토하고 피드백을 제공합니다.

## 코딩 표준

Go 팀은 코드의 일관성을 중요하게 생각합니다.

- **이름 지정 (Naming)**: Go의 [Effective Go](https://go.dev/doc/effective_go) 가이드를 따르세요.
- **단순성**: 복잡한 추상화보다는 단순하고 명확한 구현을 선호합니다.
- **에러 처리**: Go의 표준 에러 처리 패턴을 사용하세요.

## 테스트 및 빌드

변경 사항을 검증하려면 다음 명령어를 사용하세요.

```bash
# 모든 테스트 실행
go test ./...

# 특정 패키지 테스트 실행
go test path/to/package

# 도구 모음 빌드
all.bash
```

## 기여 시 주의사항

| 항목 | 지침 |
| :--- | :--- |
| **커밋 메시지** | 명확하고 간결하게 작성하며, 관련 이슈 번호를 포함하세요. |
| **범위** | 하나의 변경 사항(PR/이슈)에는 하나의 논리적 변경만 포함하세요. |
| **호환성** | Go 1 호환성 약속(Compatibility Promise)을 깨뜨리는 변경은 엄격히 제한됩니다. |

더 자세한 내용은 [Go Wiki](https://github.com/golang/go/wiki)를 참조하십시오.

Go는 오픈 소스 프로젝트입니다.

수백 명의 기여자가 함께 만든 결과물입니다. 도움을 주셔서 감사합니다!

## 이슈를 제기하기 전에

버그를 찾은 것이 확실하지 않은 경우, 먼저 [golang-nuts 메일링 리스트](https://groups.google.com/forum/#!forum/golang-nuts)나 [다른 포럼](https://golang.org/help/)에 문의하는 것을 고려해 주십시오. 확인하신 동작이 버그나 이슈로 확인되면, 이슈 트래커에 쉽게 다시 제기할 수 있습니다.

## 이슈 제기(Filing issues)

민감한 보안 관련 문제는 [security@golang.org](mailto:security@golang.org)로 보고해 주세요.
자세한 내용은 [보안 정책](https://golang.org/security)을 참조하시기 바랍니다.

이슈를 제기하는 권장 방법은 `go bug`를 실행하는 것입니다.
그 외에 이슈를 제기할 때는 다음 다섯 가지 질문에 반드시 답해 주세요:

1. 사용 중인 Go 버전은 무엇인가요 (`go version`)?
2. 사용 중인 운영체제와 프로세서 아키텍처는 무엇인가요?
3. 어떤 작업을 수행하셨나요?
4. 기대했던 결과는 무엇인가요?
5. 대신 어떤 결과가 나타났나요?

변경 제안에 대해서는 [Proposing Changes To Go](https://go.dev/s/proposal-process)를 참조하세요.
