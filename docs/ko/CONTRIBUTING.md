# Go에 기여하기

Go 프로젝트에 기여해주셔서 감사합니다! Go의 핵심 개발 팀은 커뮤니티의 도움을 받아 언어와 도구 모음을 개선하는 것을 환영합니다.

## 제안 및 이슈 보고

새로운 기능 제안이나 버그 보고는 [GitHub Issues](https://github.com/golang/go/issues)를 통해 제출해 주세요.

### 이슈 제출 시 가이드라인

*   **검색 먼저 하기:** 유사한 이슈가 이미 보고되었는지 확인해 주세요.
*   **명확하게 작성하기:** 문제의 증상, 재현 방법 및 기대 결과가 포함되어야 합니다.
*   **최소 재현 예제 제공:** 가능하다면 [Playground](https://play.golang.org/) 링크나 작은 테스트 케이스를 함께 제공해 주세요.

## 코드 기여하기

Go의 소스 코드는 [GitHub mirror](https://github.com/golang/go)에서 확인할 수 있지만, 공식적인 변경 사항 관리는 [Gerrit](https://go-review.googlesource.com/)을 통해 이루어집니다.

### 개발 환경 설정

1.  Go 소스 코드를 로컬에 복제합니다.
2.  `src` 디렉토리에서 작업을 수행합니다.
3.  변경 사항을 테스트하려면 `go test ./...` 명령어를 사용하세요.

### 제출 프로세스

1.  **변경 사항 작성:** 코드를 수정하고 관련 테스트를 추가합니다.
2.  **리뷰 요청:** Gerrit을 통해 변경 사항을 업로드하고 리뷰어에게 요청을 보냅니다.
3.  **피드백 반영:** 리뷰어의 의견에 따라 코드를 수정하고 다시 업로드합니다.
4.  **승인 및 병합:** 필요한 승인을 얻으면 변경 사항이 마스터 브랜치에 병합됩니다.

## 코딩 스타일 가이드

Go는 일관성을 중요하게 생각합니다. 다음 도구들을 사용하여 코드를 정리해 주세요.

*   `gofmt`: 코드를 표준 Go 스타일로 자동 포맷팅합니다.
*   `go vet`: 일반적인 오류나 의심스러운 구문을 검사합니다.

## 문서 기여

문서의 오타 수정이나 개선 사항은 언제든 환영합니다. 문서 변경 사항 역시 위와 동일한 Gerrit 프로세스를 통해 제출하거나, 간단한 수정의 경우 GitHub PR을 통해 논의할 수 있습니다.

## 행동 강령 (Code of Conduct)

모든 기여자는 서로를 존중하고 포용하는 환경을 만드는 데 동참해야 합니다. 자세한 내용은 [Code of Conduct](https://go.dev/coc)를 참조하세요.

Go는 오픈 소스 프로젝트입니다.

수백 명의 기여자가 함께 만든 결과물입니다. 여러분의 도움에 감사드립니다!

## 이슈를 제기하기 전에

버그를 발견한 것이 맞는지 확실하지 않다면, 먼저 [golang-nuts 메일링 리스트](https://groups.google.com/forum/#!forum/golang-nuts)나 [다른 포럼](https://golang.org/help/)에 문의하는 것을 고려해 주세요. 현재 겪고 있는 동작이 버그나 이슈로 확인되면, 이슈 트래커에 쉽게 다시 제기할 수 있습니다.

## 이슈 제기하기

민감한 보안 관련 문제는 [security@golang.org](mailto:security@golang.org)로 보고해야 합니다.
자세한 내용은 [보안 정책](https://golang.org/security)을 참조하십시오.

이슈를 제기하는 권장 방법은 `go bug`를 실행하는 것입니다.
그 외의 방법으로 이슈를 제기할 때는 다음 다섯 가지 질문에 반드시 답해 주세요:

1. 어떤 버전의 Go를 사용하고 계신가요 (`go version`)?
2. 어떤 운영 체제와 프로세서 아키텍처를 사용하고 계신가요?
3. 어떤 작업을 수행하셨나요?
4. 기대했던 결과는 무엇인가요?
5. 실제로 나타난 결과는 무엇인가요?

변경 제안에 대해서는 [Proposing Changes To Go](https://go.dev/s/proposal-process)를 참조하십시오.

## 코드 기여하기

패치를 보내기 전에 [Contribution Guidelines](https://golang.org/doc/contribute.html)를 읽어주시기 바랍니다.

별도의 언급이 없는 한, Go 소스 파일은 LICENSE 파일에 명시된 BSD 스타일 라이선스 하에 배포됩니다.
