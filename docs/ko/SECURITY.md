# 보안 정책 (Security Policy)

## 지원 버전

저희는 최신 두 개의 Go 릴리스를 지원합니다 (예를 들어, Go 1.18.x가 최신 안정 버전일 때 Go 1.17.x와 Go 1.18.x를 지원합니다).

https://go.dev/wiki/Go-Release-Cycle 를 참조하시고, 특히 해당 페이지의 [Release Maintenance](https://go.dev/wiki/Go-Release-Cycle#release-maintenance) 부분을 확인하십시오.

## 취약점 제보하기

취약점 보고 방법은 https://go.dev/security/policy 를 참조하세요.
