# 보안 정책 (Security Policy)

## 지원 버전

우리는 최근 두 개의 Go 릴리스를 지원합니다 (예를 들어, Go 1.18.x가 최신 안정 릴리스일 때 Go 1.17.x 및 Go 1.18.x를 지원합니다).

https://go.dev/wiki/Go-Release-Cycle 를 참조하시고, 특히 해당 페이지의 [Release Maintenance](https://go.dev/wiki/Go-Release-Cycle#release-maintenance) 부분을 확인하시기 바랍니다.

## 취약점 제보하기

취약점 보고 방법은 https://go.dev/security/policy 를 참조하십시오.
