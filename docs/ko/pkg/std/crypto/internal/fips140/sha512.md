## 한국어 요약

패키지 sha512는 FIPS 180-4에서 정의된 SHA-384, SHA-512, SHA-512/224, 및 SHA-512/256 해시 알고리즘을 구현합니다.

## 원문 요약

Package sha512 implements the SHA-384, SHA-512, SHA-512/224, and SHA-512/256 hash algorithms as defined in FIPS 180-4.
