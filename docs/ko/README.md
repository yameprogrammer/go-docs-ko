# Go 프로그래밍 언어

Go는 단순하고 신뢰할 수 있으며 효율적인 소프트웨어를 쉽게 구축할 수 있게 해주는 오픈 소스 프로그래밍 언어입니다.

![Gopher image](https://golang.org/doc/gopher/fiveyears.jpg)
*[Renee French][rf]가 제작한 Gopher 이미지이며, [Creative Commons 4.0 Attribution license][cc4-by]에 따라 라이선스가 부여됩니다.*

우리의 공식 Git 저장소는 https://go.googlesource.com/go 에 위치해 있습니다.
해당 저장소의 미러 사이트는 https://github.com/golang/go 에 있습니다.

별도로 명시되지 않는 한, Go 소스 파일은 LICENSE 파일에 명시된 BSD 스타일 라이선스에 따라 배포됩니다.

### 다운로드 및 설치

#### 바이너리 배포판

공식 바이너리 배포판은 https://go.dev/dl/ 에서 이용 가능합니다.

바이너리 릴리스를 다운로드한 후, 설치 지침을 확인하려면 https://go.dev/doc/install 을 방문하십시오.

#### 소스에서 설치하기

사용 중인 운영 체제와 아키텍처 조합에 맞는 바이너리 배포판을 사용할 수 없는 경우, 소스 설치 안내를 위해 https://go.dev/doc/install/source 를 방문하시기 바랍니다.

### 기여하기

Go는 수천 명의 기여자들이 함께 만든 결과물입니다. 여러분의 도움에 감사드립니다!

기여하시려면 https://go.dev/doc/contribute 의 기여 가이드라인을 읽어주시기 바랍니다.

Go 프로젝트의 이슈 트래커는 버그 보고 및 제안 용도로만 사용됨에 유의하십시오. Go 언어에 대해 질문할 수 있는 곳들의 목록은 https://go.dev/wiki/Questions 를 참조하십시오.
